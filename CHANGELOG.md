# Changelog

All notable changes are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[semantic versioning](https://semver.org/).

## [2.0.1] - 2026-09-24

### Fixed

- Heavy-tail experiment: every process now has priority 0, 100 tickets and
  nice 0, so CFS-lite is compared on equal terms (its mean slowdown at
  alpha = 1.1 is 4.71, not 7.00; from alpha = 1.5 on it beats Round Robin).
  The policy-comparison takeaway notes that weighted policies use the
  generator's random weights.
- `--gap` text output says "below" when a preemptive policy beats the
  non-preemptive optimum, instead of printing a negative "above".
- `make perf-compare` finds its baseline commit by subject, so rewriting
  history no longer breaks it.
- Web visualiser: metrics columns use consistent decimals.

### Changed

- Web visualiser redesign: sidebar setup, highlight tiles, animated
  timeline with speed control, shareable links, light/dark toggle, and a
  results-first layout on phones.
- `docs/results` regenerated and labelled with the commit that produced it.

## [2.0.0] - 2026-09-23

A rewrite from a single file into a tested, modular scheduling lab. The
schedules and default output of the four original policies are unchanged
(checked byte for byte against the original program's output).

### Added

- Event-driven engine with a pluggable policy interface; one file per policy.
- Policies: priority (non-preemptive and preemptive, with aging), HRRN, MLFQ
  (OSTEP rules: allotments, boost), lottery (reproducible seed), stride,
  CFS-lite, and `opt-np`, the exact non-preemptive optimum (up to 20
  processes).
- Machine model: multiple cores with one ready queue, context-switch cost, I/O
  phases, EWMA burst prediction with MAE/MAPE and regret against the oracle.
- Metrics: median, p95, p99 and max of turnaround, waiting and response;
  slowdown; Jain's fairness index; throughput; utilisation; switch overhead;
  optimality gap (`--gap`).
- Input: CSV files with optional `bursts`, `priority`, `tickets` and `nice`
  columns. Output: text, CSV, JSON (documented schema), summary CSV,
  `--format=none --timing` for benchmarks.
- Interactive WebAssembly visualiser deployed to GitHub Pages.
- Workload generator (`tools/gen.py`), benchmarks and seven experiments, all
  regenerated by `make experiments` into `docs/results/`.
- Tests: golden, hand-computed, differential against an independent
  tick-by-tick reference simulator, schedule properties, optimality theorems,
  CLI, fuzzing (libFuzzer in CI), WebAssembly-vs-native; CI on gcc, clang and
  macOS with sanitizers, coverage and formatting checks.
- Documentation: model specification, design notes, JSON schema, this
  changelog, contributing guide, MIT licence.

### Fixed

- `--algo=` never matched (the option parser compared 8 characters of a
  7-character prefix).
- Signed integer overflow for large bursts: all times are now 64-bit and
  validated against overflow.
- Duplicate PIDs are rejected instead of producing ambiguous output.
- README claims that did not match the program (file names, input rules,
  sample output).

### Changed

- The FCFS Gantt chart starts at the first arrival like every other policy's
  (the original drew an idle segment from t=0).
- Invalid input exits with distinct codes: 1 invalid input, 2 usage,
  3 I/O, 4 out of memory.

## [1.0.0] - 2025-08-13 (untagged)

- Original single-file simulator: FCFS, SJF, SRTF and Round Robin with
  interactive input, Gantt charts and CSV output.
