# Fuzzing record

The libFuzzer harness is `tests/fuzz/fuzz_input.c` (parsers, then every policy
on small valid workloads with schedule invariants checked), built with
AddressSanitizer and UndefinedBehaviorSanitizer. CI fuzzes it for 5 minutes on
every push and 1 minute on every pull request, starting from
`tests/fuzz/corpus/`.
